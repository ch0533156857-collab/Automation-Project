# 🤖 Automation Project

Web automation testing project using Selenium and Java.

## 🛠️ Tech Stack

- **Language:** Java
- **Framework:** Selenium WebDriver
- **Build Tool:** Maven

## 🚀 Run Tests

```bash
mvn test
```

## 📁 Project Structure

```
Automation-Project/
├── src/
│   └── test/        # Test classes and page objects
└── pom.xml          # Maven dependencies
```

## 📋 What's Tested

Automated end-to-end testing of web application flows including form submissions, navigation, and UI validations.
